- Python To-Do List App

  A simple command-line To-Do List application built with Python. This project allows users to manage their daily tasks through an interactive menu.
  ## Features
  - **Add Tasks** – Create new tasks with unique IDs.
  - **Show Tasks** – Display all tasks with their IDs and current statuses.
  - **Delete Tasks** – Remove tasks by their IDs.
  - **Edit Tasks** – Change existing task names.
  - **Complete / Restore Tasks** – Mark tasks as completed or return them to "In Progress".
  - **Task Statistics** – View the total number of tasks, completed tasks, and tasks still in progress.

  - Functions and modular code organization.
  - Data structures: Lists and Dictionaries.
- Working with user input and output.

- Importing functions from separate Python modules.

## Input Validation & Error Handling

The application includes basic input validation and error handling to prevent common user input errors and keep the program running smoothly.

- Handles non-numeric input when selecting menu options or task IDs.
- Prevents empty task names.
- Checks whether a task exists before editing, deleting, or changing its status.
- Validates menu selections and handles invalid options.
- Handles invalid responses when restoring completed tasks.

The goal is to make the application more user-friendly and prevent common input mistakes from interrupting its execution.
